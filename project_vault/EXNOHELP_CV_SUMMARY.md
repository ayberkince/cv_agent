# Project: Exnohelp Mobile (CV Summary & Tech Stack)

Below is a curated description and technical stack list of the **Exnohelp Mobile** project, structured for immediate inclusion in a resume/CV.

---

## 📄 Project Summary
**Exnohelp Mobile** is a cross-platform mobile application designed to connect vulnerable individuals (clients) with trusted companions to provide safe, non-medical support during key life events (such as medical appointments, waiting rooms, returning home, or managing paperwork).

---

## 🛠️ Tech Stack & Key Technologies
* **Core Framework:** React Native (Expo SDK 54)
* **Programming Language:** TypeScript
* **Routing & Navigation:** Expo Router (File-based navigation, supporting deep-linked Stack/Tab structures)
* **Styling & Layouts:** React Native Stylesheets, React Native Safe Area Context (notch/edge-to-edge support), Expo Vector Icons
* **Interactions & Feedback:** Expo Haptics (tactile/haptic feedback), React Native Reanimated (ui animations), React Native Gesture Handler
* **Tooling & Build System:** Expo CLI, ESLint, TypeScript compiler, React Compiler (Experimental support enabled)

---

## 💼 CV Bullet Points (Accomplishments & Features)
* **Cross-Platform Mobile Development:** Built and styled a cross-platform mobile application using **React Native**, **Expo (SDK 54)**, and **TypeScript** targeting iOS, Android, and Web platforms.
* **Architecture & Navigation:** Engineered dynamic navigation flows for separate user roles (Clients and Helpers) using **Expo Router**, implementing clean stack and screen management structures.
* **Modern UI & Aesthetic Styling:** Designed and crafted a highly responsive, modern interface featuring a cohesive Sage Green palette, optimized layouts, and custom typography to prioritize accessibility and usability.
* **Responsive Layout Design:** Leveraged `react-native-safe-area-context` to guarantee responsive rendering and consistent alignment across all device screens and notch styles.
* **Tactile Interactions:** Programmed sensory-rich physical feedback and micro-interactions utilizing **Expo Haptics** and **React Native Reanimated** to elevate user satisfaction and polish.
