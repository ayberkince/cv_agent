# NATURAL X‑Y‑Z BULLET PROTOCOL
- Every bullet must answer: **What was built? How was it executed technically? What was the quantifiable magnitude/impact?**
- **FORBIDDEN** robotic phrases: "as measured by", "by doing".
- **BANNED weak verbs**: Supported, Responsible for, Helped, Assisted, Participated in.
- **Preferred strong action verbs**: Engineered, Optimised, Automated, Reduced, Architected, Built, Led, Increased, Formulated, Designed, Synthesised.
- Example good bullet: *Engineered a responsive market intelligence dashboard in Streamlit running on a custom SQLite backend, indexing 5,000+ global headlines via automated REST API ingestion loops.*
- Example bad bullet: *Built a dashboard as measured by data loading, by using SQLite.*
