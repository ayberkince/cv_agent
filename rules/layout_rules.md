# LAYOUT & ATS RULES
- Single‑column layout, no tables, no graphics.
- Use exact section headers: `## Professional Summary`, `## Technical Skills`, `## Projects`, `## Experience`, `## Education`, `## Language Skills`, `## Certifications`.
- Date format: `MM.YYYY – MM.YYYY` (e.g., `09.2023 – 09.2024`).
- Use `<span class="date">` for right‑aligned dates.
- Cv must be maximum 2 pages.
-Cover letter must be maximum 1 page.
